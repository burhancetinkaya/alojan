Alojan

Your calls. Your AI agents. Your infrastructure.

Alojan is an open-source, self-hosted AI voice agent engine for real-time phone conversations.

Build intelligent phone agents that listen, understand, speak, and take action — all on your own infrastructure.

Features (Planned)

* Native SIP/RTP telephony integration
* Real-time speech recognition and streaming TTS
* Intelligent turn detection and natural interruptions
* LLM-powered conversations with tool calling and MCP
* Call transcription, summaries, and structured logs
* Self-hosted deployment with Docker and GPU acceleration
* Turkish-first voice experience

Architecture

SIP → C++ Voice Engine → STT → AI Agent → TTS → SIP

Technology

C++20 · PJSIP · Python · OpenAI Agents SDK · Whisper · EMA Lightning · Smart Turn · Docker · PostgreSQL

Project Status

Early development — not yet production-ready.

The initial goal is to build a fully self-hosted AI phone assistant, with a modular architecture that can evolve into a general-purpose voice agent framework.

Philosophy

Your calls. Your AI agents. Your infrastructure.

No dependency on hosted voice agent platforms.
