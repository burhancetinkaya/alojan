# Code of conduct

Alojan contributors and maintainers must treat people respectfully, regardless of background, identity, experience, or ability. Give specific technical feedback, accept corrections, and credit others' work.

Harassment, threats, discriminatory language, sexual harassment, publication of private information, and repeated disruptive behavior are not acceptable. These rules apply to repository issues, pull requests, discussions, and project events.

## Reporting and enforcement

Report concerns to a maintainer using an established private contact when available. Until a private conduct-reporting channel is published, request one from the maintainer without posting incident details or identifying the affected person publicly. Security reports follow `SECURITY.md` instead.

Maintainers should protect reporter privacy, hear relevant context, disclose conflicts of interest, and respond proportionately. Responses can include a request to edit content, a warning, temporary participation restrictions, or removal for serious or repeated misconduct. A person involved in a complaint should not decide its outcome alone; ask an uninvolved maintainer to review when available.

A published private reporting contact is required before broad community onboarding. No response-time commitment is made while this project is in preparation.
