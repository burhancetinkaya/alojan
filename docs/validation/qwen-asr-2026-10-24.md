# Qwen3-ASR-1.7B comparison — 2026-10-24

M2-01 / M5-03; requirements §8.1, US-02/04/06; ADR 0003 and ADR 0008.
The owner requested evaluation and promotion only if better than Whisper.

## Decision

Retain the resident faster-whisper large-v3-turbo backend. Qwen regressed human
clean, PCMA and noisy PCMA recognition, curated product spelling and a short
interruption phrase. Its whole-utterance inference was slower in the tested
Transformers configuration. Lower pooled quiet-speech error does not outweigh
these regressions. No live service, model selection or carrier configuration changed.

retain their upstream terms. No model/data redistribution approval is implied.
Weights finished downloading on Linux in about 5.6 minutes. A parallel Mac
fallback download was stopped when Linux finished; no partial file was used.

## Human speech results

WER is pooled word edits divided by reference words; lower is better.

| Condition, 24 recordings each | Whisper WER | Qwen WER | Qwen better / tied / worse recordings |
| --- | ---: | ---: | --- |
| Clean 16 kHz | 7.24% | 9.65% | 2 / 14 / 8 |
| 8 kHz PCMA round trip | 11.40% | 17.11% | 1 / 9 / 14 |
| PCMA + deterministic 10 dB noise | 24.56% | 32.02% | 8 / 3 / 13 |
| Quiet PCMA, approximately -24 dB | 21.93% | 17.11% | 4 / 5 / 15 |

Quiet pooled WER improves despite 15 recordings worsening; a few high-error
baseline recordings dominate that aggregate. It is not uniform robustness.

| PCMA inference | Whisper | Qwen |
| --- | ---: | ---: |
| Human P50 | 142 ms | 439 ms |
| Human P95 | 180 ms | 731 ms |
| Synthetic P50 | 112 ms | 195 ms |
| Synthetic P95 | 123 ms | 320 ms |

These are single-pass unpaced whole-utterance timings, not first-token latency,
partial transcription, endpoint-to-RTP or concurrency acceptance. vLLM and
FlashAttention were not tested; the speed result applies to this runtime, not
every possible Qwen deployment. Recognition regressions already block promotion.

Qwen peak PyTorch allocated memory was 4,698,449,408 bytes (~4.38 GiB).
Whole-device memory observed during the run was 11,447 MiB versus 6,626 MiB
before/after; the spot sample is not a continuously measured device peak.
There was no OOM. These figures include different allocation boundaries and do
not establish five-call capacity or long-utterance safety.

## Synthetic entities and controls

| Condition, 16 utterances each | Whisper literal WER | Qwen literal WER | Whisper / Qwen entity misses |
| --- | ---: | ---: | ---: |
| Clean | 19.23% | 6.15% | 1 / 2 |
| PCMA | 19.23% | 7.69% | 1 / 2 |
| Noisy PCMA | 21.54% | 23.85% | 2 / 2 |
| Quiet PCMA | 19.23% | 9.23% | 1 / 2 |

The lower synthetic literal WER partly reflects number formatting: references
spell numbers out, Qwen often does likewise, while Whisper often uses digits.
It must not be reported as equivalent semantic improvement. On synthetic PCMA,
Qwen changed “Bir dakika” to “bütün kika”, misrecognized the curated product
name, and introduced an extra word/number around the date/time phrase. The
phone-number utterance also contained word errors. This is qualitative inspection,
not a normalized digit-accuracy benchmark. Only three curated brand/product
entity labels exist per condition; human FLEURS entity accuracy is unmeasured.

One- and five-second exact digital silence returned empty through the shared
zero-input guard. Both models emitted text for both seeded Gaussian-noise
controls (seed 41, standard deviation 0.003). These controls bypass the gateway's
external VAD; they do not prove a live false activation. Details stay in ignored
`.local/qwen-eval/` and no caller recording was enabled.

passed. Existing Python 3.12 audioop deprecation warning remains. The actual CUDA
runs validate model execution separately from these deterministic tests.

No production adapter was introduced because quality failed promotion. Streaming,
gRPC cancellation/generation isolation with Qwen, native SIP integration, human
handset evaluation and concurrency/soak tests were not run for this candidate.

(15073) all returned SERVING; whole-device memory returned to 6,626 MiB.
Relative documentation links and diff whitespace checks passed.
