# Self-service UI fixes — 2026-10-27

AGP-06/07/09, M4–M5, ADR 0011, requirements §11.2, US-08.
Resolves all three findings from [the UI review](ui-review-2026-10-27.md).

## Corrected behavior

- Unsaved agent configuration survives same-document Back/Forward navigation in
  session memory. Drafts are scoped by workspace and agent, cleared on logout or
  session change, and retain the original version for conflict detection. A global
  unload warning also protects cached drafts while the editor is not mounted.
  Drafts are not persisted to browser storage; full reload/session end discards them.
- An uncertain agent-creation response blocks a blind second submission and asks
  the user to check the authoritative agent list. Both dropped responses and server
  errors after successful creation are covered. This is UI uncertainty handling,
  not a new backend idempotency contract.
- Unsafe MCP integers retain their typed text and display a validation error;
  applying and saving are blocked rather than silently sending a rounded number.
  Recursive validation also blocks existing unsafe nested numeric configuration
  from being saved through an unrelated edit. Safe numeric values retain their type.
