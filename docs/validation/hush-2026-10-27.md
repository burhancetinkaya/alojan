# Hush before Silero: isolated evaluation — 2026-10-27

M3-02, M5-03, VXP-06; US-05/06; ADR 0003/0014. The owner requested Hush and
explicitly retained Silero. This evaluates **incoming PCM → Hush → unchanged
Silero / unchanged Whisper**, not a VAD replacement. No serving path was changed.

## Decision

Do not enable the tested default Hush configuration globally. It prevented only
2 of 20 background-only sustained-threshold crossings and erased the quiet clean
target in all four long-utterance controls. Silero missed them and the ASR backend's
digital-silence guard returned empty text. The gentler 20 dB attenuation cap retained these utterances
but prevented none of the 20 background crossings. Some overlap recognition
improved; that benefit does not satisfy the false-interruption and preservation
gates together. The noisy-room handset issue remains open.

These counts describe a small controlled offline set, not production failure
rates or a rejection of all possible Hush configurations/training revisions.

## Cases and scoring

34 continuous streams / **727.68 seconds**, each processed as bypass, Hush default
100 dB/unlimited attenuation, and Hush 20 dB maximum attenuation: 102 profile-streams.
Both filters start from a new independent session. Public FLEURS Turkish human
`fleurs-1853-1`, synthetic EMA `greeting` and `interrupt` are hash verified using
the existing manifest SHA-256
`dad31c9e7753ae3b0fae450ca872b99852464f02594809ba7bb5b019ef3e7955`.
No private caller recording was used or created.

The cases are the same 34-stream set used by the neovad follow-up: both main voice
roles, PCMA/PCMU at 8 kHz round-tripped to 16 kHz, clean, quarter-peak background,
equal peaks, background starting first, quarter-peak target, and clean target
attenuated 24 dB. Short normal/quiet interruptions occur with and without another
speaker; silence is a control. Peaks are controlled, not RMS SIR, microphone
distance or reverberation. Only two main voices are represented. The upstream
training claim of 12–24 dB SIR is not reproduced as a calibrated SIR benchmark.

Hush receives 160 samples per call. Near-zero attenuation (0.001 dB) and continuous
calibration noise measure the DSP path's **160-sample/10 ms signal delay** with
RMSE 5.74e-6. Exactly 0 dB activates a separate upstream passthrough shortcut;
the initial calibration assertion caught this, and no measurements from that
failed setup were included. The evaluation aligns filtered audio by this fixed
delay for paired quality scoring and accounts for it separately from processing
time. Five zero frames are supplied at the tail; the upstream low-energy shortcut
can return zero without advancing DSP state, so this is not a general lossless
flush guarantee. The native library/model are tested as shipped, not patched.

The PCM16 boundary is retained before Silero/ASR; no out-of-range output samples
were observed. Silero's 512-sample cadence and 64-sample context are unchanged.
`voice_trial.py` replays the existing 0.5 / 640 ms sustained-voice / 160 ms quiet-gap
rule within each window. It excludes ASR-assisted interruption, echo filtering and
native scheduling. A threshold crossing is not an actual telephone interruption.
Window boundaries start with empty evidence and include utterance pauses.

Recognition: **96 checks: 92 real CUDA Whisper large-v3-turbo decodes and four
digital-silence short circuits**, unchanged beam 5,
no extra VAD or vocabulary correction; second target utterance only, all three
profiles. Filtered WAVs and recognition output remain in ignored development
storage. Silence controls were not forced through ASR. Window transcription does
not prove real-time endpoint behavior or speaker identity during overlap.

## Results

| Outcome | Bypass + Silero | Strong Hush + Silero | Gentle Hush + Silero |
|---|---:|---:|---:|
| Later background-only false crossings | 20/20 | 18/20 | 20/20 |
| Initial background-only false crossings | 4/4 | 4/4 | 4/4 |
| Quiet clean long targets detected by sustained rule | 4/4 | 0/4 | 4/4 |
| Quiet clean long targets with nonempty ASR | 4/4 | 0/4 | 4/4 |

Strong Hush's two prevented background crossings are in the quieter-background
condition. There, background-only energy drops 7.5–26.8 dB depending on voice/codec;
equal/louder competing speech still reliably triggers Silero. Neither mode identifies
the intended caller merely because the other voice began first.

Literal word-error counts in target windows (errors may exceed the reference
length due to insertions/background words):

| Condition | Reference words | Bypass | Strong Hush | Gentle Hush |
|---|---:|---:|---:|---:|
| Clean | 54 | 4 | 8 | 6 |
| Quieter background | 54 | 6 | 7 | 6 |
| Equal-peak background | 54 | 50 | 36 | 34 |
| Background first | 54 | 48 | 50 | 48 |
| Quiet target under louder speech | 54 | 58 | 72 | 58 |
| Quiet clean | 54 | 6 | 54 | 7 |
| Normal short phrase with background | 4 | 0 | 0 | 0 |
| Normal short phrase alone | 4 | 0 | 0 | 0 |
| Quiet short phrase with background | 4 | 0 | 5 | 0 |
| Quiet short phrase alone | 4 | 0 | 0 | 0 |

The quiet clean failure is confirmed by all-zero PCM and empty text, not inferred
from attenuation alone. Whisper is not invoked on those four erased windows.
Strong Hush's quiet short phrase with background also degrades recognition.
Gentle filtering helps equal-level overlap in this set, but clean recognition does
not improve and background-driven false interruption remains unresolved.

Model construction was 67.2 ms, outside frame timing. Filter sessions are called
sequentially for quality/performance runs; input is unpaced. These figures exclude
ASR and network/packet scheduling, and do not establish five-call capacity or
hard real-time deadlines. The measured DSP delay is additional to processing time.

Passed on Linux: both codec/fixture checks, policy boundaries, fixed DSP calibration,
fresh-state/reset equivalence, two parallel independent sessions matching sequential
results, and Ruff. Shared fixture/scoring functions were moved without AST changes
from the neovad driver; its model/parity/reset self-checks passed again after the
refactor. The ASR scorer retains the old VoxLock defaults and adds explicit profile,
case-count and window selection for this trial. Mac Ruff also passed.
