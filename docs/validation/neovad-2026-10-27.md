# neovad CPU screening — 2026-10-27

M3-02, M5-03, VXP-06; US-05/06; ADR 0003/0014. Owner requested a free neovad
trial for false interruptions caused by other people talking near a speakerphone.

## Decision

Do not replace the serving Silero detector with this candidate yet. The bundled
pretrained GRU reduces competing-speech activation in some conditions but does
not reliably distinguish the intended caller. In the measured 30-stream run,
16/20 background-only windows with competing speech crossed the existing
640 ms sustained-evidence threshold, versus 20/20 for Silero. These are offline
threshold crossings, not counts of actual interrupted telephone calls.

There is useful partial improvement, but it does not close the noisy-room handset
gate. No live configuration, agent binding, container or audio path was changed.

## Method

30 streams / 667.20 seconds, using the existing FLEURS Turkish human sample
`fleurs-1853-1`, synthetic EMA `greeting` and short `interrupt` ("Bir dakika").
The human/synthetic target and background roles are exchanged in the six long
conditions, with PCMA and PCMU for each. Four further streams exercise short
interruptions; two are silence controls. Both models receive identical continuous
G.711 round-tripped 8 kHz telephone audio upsampled to 16 kHz.

The conditions are clean, quarter-peak background, equal peaks, background
starting first, quarter-peak target, and clean target attenuated by 24 dB. These
are controlled levels, not calibrated physical distance or room acoustics.
Fixtures include repeated content and only two main voices; they are not a
representative speaker/language benchmark.

Every stream uses fresh state. Both receive 32 ms chunks; neovad yields three or
four 10 ms predictions per chunk. The main adapter uses the latest primary-class
probability, with mean/max aggregation and any-speech probabilities as sensitivity
checks. No neovad hysteresis wrapper is added to the existing threshold rule.

Within each scoring window, blocks wholly inside it are thresholded at 0.5.
The replay accumulates 640 ms of positive evidence, resetting after at least
160 ms of intervening negative blocks, as in the native no-transcript fallback.
Evidence starts empty at the window boundary. It omits ASR, echo filtering,
full interruption scheduling and native RTP timing. Window-positive percentages
include utterance pauses: they are not labelled speech recall or recognition
accuracy. A positive during overlapping speech does not identify which person
was detected. The final partial block (<32 ms) is not scored.

## Measured results (first run)

| Competing-speech condition | Background false crossings, Silero | Background false crossings, neovad | Background window positive, Silero / neovad |
|---|---:|---:|---:|
| Quieter background | 4/4 | 4/4 | 90.7% / 28.5% |
| Equal peaks, target first | 4/4 | 4/4 | 91.2% / 77.1% |
| Background first, later background-only gap | 4/4 | 0/4 | 91.3% / 21.6% |
| Quiet target, louder background | 4/4 | 4/4 | 91.7% / 85.7% |
| Normal-level short interruption scenario | 2/2 | 2/2 | 100% / 82.4% |
| Quiet short interruption scenario | 2/2 | 2/2 | 100% / 94.2% |

The background-first result concerns the later five-second gap **after the
caller has been heard**, not the initial five seconds with only background speech.
Max aggregation changes that result to 2/4 false crossings; mean remains 0/4.
This sensitivity is another reason not to treat an adapter choice as qualified.

Clean and clean quiet long utterances activated both detectors in all four
cases per condition; their silent gaps and both silence controls had no false
crossing. For the quiet short phrase over background, neovad primary was positive
in 28.3% of the utterance window. None of the four short mixed-voice windows
reached 640 ms with neovad; this does **not** prove the native agent would miss
the interruption, because fresh ASR text provides a separate path and delayed
evidence outside that narrow window is not counted. Silero positivity under
overlap also cannot prove correct caller detection.

## Performance and checks

| CPU measurement across 30 streams | Silero | neovad GRU |
|---|---:|---:|
| Largest per-stream P95 block processing time | 0.075 ms | 0.689 ms |
| Worst observed block | 24.744 ms | 1.988 ms |
| Largest timed work / audio duration ratio | 0.00281 | 0.01912 |
| Blocks over 32 ms | 0 | 0 |

Measurements include synchronous adapter/postprocessing work, after self-check
warm-up; initialization is excluded. Input was fed unpaced. They are not
end-to-end latency, concurrent-call capacity or hard real-time guarantees.

Linux Ruff checks passed. Executed self-checks passed for both codecs/fixture
windows, sustained-evidence reset boundaries, fresh-state repeatability for both
models and neovad streaming/batch probability parity (atol/rtol 1e-4).

First-run detailed results remain at Linux `.local/neovad-eval/results.json`;
its aggregate was retrieved successfully. A follow-up run added scoring of the
initial background-only interval plus isolated normal/quiet short phrases with
an extra 500 ms tail. Its command and Ruff checks exited successfully, but SSH
became unreachable before `.local/neovad-eval/results-v2.json` could initially be
retrieved. It was retrieved during the subsequent Hush task after connectivity
returned, and this report was synchronized. SHA-256:
`50fa38398b3b184a5ea26b317f390c00159a57d12426e85d91e3e25b81cafefa`.
The expanded set is 34 streams / 727.68 seconds. Both Silero and neovad crossed
the sustained threshold in **all four initial background-only windows**. Both
detected all four isolated short phrases when the 500 ms tail was included;
neovad's quiet short-phrase crossings were 688/784 ms from clip start. These are
additional controls, not replacements for the first-run table above. Shared case
and scoring functions now reside in `voice_trial.py`; AST equality and Linux
model/reset/streaming-parity checks confirm unchanged fixture/scoring behavior.

No native SIP integration, handset acceptance, ASR accuracy trial or GPU inference
was performed. The serving noisy-room quality issue remains open.
